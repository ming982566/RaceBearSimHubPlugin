Corrects the byte order regression introduced in 0.1.15. SimHub compact Binary
axis output uses big-endian bytes. Decoding it as little-endian could map the
midpoint close to full stroke and turn small changes into large position jumps.

Byte order remains fixed; 8 bit, legacy text, and comma-separated binary input
remain supported. Decoding and position mapping were checked with the actual
SimHub encoder. The signed package includes the matching x86 SDK and updater.

Users of 0.1.15 should update to 0.1.16 before further motion testing.
No configuration changes are required.
